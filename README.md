\# Power BI Senior Data Analyst Project



\## Project Overview

An end-to-end Power BI project analysing a multi-year retail sales dataset (2022–2025). The project demonstrates data preparation, data modelling, DAX, time intelligence, and business performance analysis.



\## Business Scenario

A retail business wants to understand its sales, profitability, returns, and target achievement across products, customers, stores, and employees.



\## Tools \& Technologies

\- Power BI Desktop

\- Power Query

\- DAX

\- Python (Pandas)

\- Microsoft Excel



\## Dataset

The project uses a synthetic technology retail dataset containing:

\- Sales

\- Products

\- Customers

\- Stores

\- Employees

\- Returns

\- MonthlyTargets

\- Categories



\## Project Sections

1\. Data Preparation \& Quality Checks

2\. Data Modelling

3\. DAX Measures

4\. Time Intelligence

5\. Business Performance Analysis

6\. Dashboard Development



\## Project Status

Data preparation, data modelling, basic DAX, and time intelligence are completed. Business performance analysis and dashboard development are in progress.
